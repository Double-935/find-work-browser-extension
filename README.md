# Find Work 浏览器插件（分享版原型）

这份目录可以单独复制给朋友；**不包含原使用者的简历、岗位台账或个人偏好**。首版面向 Chromium 浏览器（Chrome、Edge 等），所有资料保存在朋友自己的浏览器本地。无需 Obsidian 或模型 API Key。

## 安装

1. 下载本仓库源码并解压到朋友电脑。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 打开“开发者模式”，选择“加载已解压的扩展程序”，选中本目录。
4. 在自动弹出的设置页填写毕业年份、岗位关键词、个人排序权重及相关偏好，然后保存。简历母板可选择上传文件、粘贴文本或暂不提供。招聘域名、公开招聘页和公众号文章由插件尝试自动寻找。
5. 安装时浏览器会提示插件可读取 HTTPS 网站。这是后台定时扫描新发现网站所需的权限；插件只发起公开页面的读取请求，不携带登录凭据。
6. 点击插件图标可手动扫描或打开日报。工作日默认在本机时间 09:00、15:00、21:00 扫描；日报可选“仅工作日早九点”“每日早九点”或自定义发送日期与时间。选择每日时，周末也会在日报时间扫描并生成日报。

## 使用流程

- **发现：**先按岗位关键词跨公司搜索，再额外搜索优先关注公司。插件从公开搜索结果自动发现招聘页和公众号文章，读取其中的职位链接，并在日报展示发现的来源。优先关注公司只影响额外搜索与排序，不限制其他公司出现。公众号只处理无需登录的公开文章；搜索索引可能漏掉新文章。
- **核验：**岗位进入可投表前，必须是可识别的具体职位 URL，来源已确认，并且在可读取页面中找到职责或要求、地点/届别/实习信息和申请按钮。陌生域名、无法读取的动态页和转载进入“待用户确认”；用户可在日报直接确认具体职位来源。早报前会复核已收录岗位；暂时读不到的岗位进入“待复核”，明确关闭或过期的岗位标为“失效”。
- **排序：**每位用户自行选择求职重点并分配权重（合计 100），高匹配门槛默认 80 分、可修改。缺少可信判断依据的条件显示“信息不足”，其余可评估项按权重折算到 100 分并标出已评估权重；可评估权重不足 50 时不标为高匹配。行业、薪资与公司平台按用户设置及明确公开信息判断，不凭名称猜测。分数只是初筛。
- **早报：**每个工作日最多展示五条新岗位；未展示的岗位进入待展示队列，超过一个工作日的合格岗位获得展示优先级。可选择自动打开标签页，或仅在插件图标显示提醒。
- **反馈：**在日报填写满意度、标记和备注；“待投递”进入进度区。“已投递”只有用户手动选择后才记录，实际投递日期、渠道、简历版本与附件引用由用户填写；有实际日期且满 21 天无更新时改为“无回复”。
- **自选岗位：**在日报的“手动加入”区域填写公司、具体岗位与链接即可直接进入待投递，不受自动核验或评分限制；若职位页无法读取，请同时粘贴 JD。
- **辅助制作简历：**简历母板可上传 PDF、DOC、DOCX、TXT、Markdown、RTF 或 ODT 文件（不超过 15 MB），也可粘贴文本。未提供母板时不生成提示词。提供母板并有具体 JD 后，在待投递岗位点击“准备简历”；把提示词复制到已有的 WorkBuddy、豆包、元宝、Codex 等 AI 工具。使用文件母板时，请下载本机保存的原文件并同时附给 AI 工具；插件不解析 PDF 或 Word 内容，也不会代为上传文件。将生成的草稿粘贴回插件、核对并确认，可下载 Markdown。插件不会代投。
- **备份：**日报页可导出本机数据，或选择备份 JSON，预览后确认导入。备份不包含上传的母板文件，导入后需重新上传。导出备份后，可手动归档超过 90 天且未处理的旧线索；投递和反馈记录长期保留。

## 目前的边界

- 电脑和浏览器都须保持运行；电脑开着但浏览器完全退出时，扩展无法执行定时任务。重新打开浏览器后，会补做当天尚未完成的扫描和日报。
- 不访问需要登录、扫码或验证码的渠道，不自动投递，不自动调用朋友的 AI 账号。无 API Key 条件下，简历生成需要用户在已有 AI 工具中粘贴提示词与草稿。
- 上传的母板文件只保存在本机浏览器的 IndexedDB；插件不会把文件内容发往招聘网站、搜索引擎或 AI 工具。使用外部 AI 时，由用户自行选择是否附上文件。
- 公开网站的结构会变化。对纯前端动态渲染、图片型公众号和反爬页面，本原型可能只能记录线索，不能完成职位核验。请在日报“扫描记录”查看失败原因。
- 跨公司搜索发现的陌生域名不会自动被当作官方来源。若插件无法确认来源，用户需先打开具体职位页核对，再在日报点击“我已确认该职位来源官方”；这只确认该职位，不会信任整个域名。
- 首版对岗位要求采用关键词初筛，无法理解复杂语义；复杂的毕业年份、投递名额和截止日期需以官网为准。公司规模或阶段只有在公开职位内容中找到有日期的明确证据时才参与初筛，无法覆盖所有公司的年报与监管资料。
- 本原型已做静态检查，仍需在朋友实际使用的浏览器和目标网站逐站试用后才能作为稳定发布版。

## 文件

`manifest.json` 为扩展入口；`background.js` 负责定时扫描；`options.html` 为个人设置；`resume-store.js` 在本机保存上传的母板文件；`resume-prompt.js` 生成提示词；`report.html` 为日报、反馈、进度和简历草稿；`popup.html` 为插件入口。
