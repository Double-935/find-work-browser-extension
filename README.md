# Find Work 浏览器插件（分享版原型）

这份目录可以单独复制给朋友；**不包含原使用者的简历、岗位台账或个人偏好**。首版面向 Chromium 浏览器（Chrome、Edge 等），所有资料保存在朋友自己的浏览器本地。无需 Obsidian 或模型 API Key。

## 安装

1. 下载本仓库源码并解压到朋友电脑。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 打开“开发者模式”，选择“加载已解压的扩展程序”，选中本目录。
4. 在自动弹出的设置页填写毕业年份、关键词、目标公司与其官方招聘域名、公开招聘页或公众号文章网址、简历母板，并保存。浏览器会询问这些公开站点的读取权限。
5. 点击插件图标可手动扫描或打开日报。工作日将按本机时间自动扫描，默认 09:00、15:00、21:00，日报默认 09:00；时间可改。

## 使用流程

- **发现：**按目标公司名称在 Bing 公开搜索及公开公众号文章索引中查找候选链接，同时读取用户配置的公开招聘页。公众号只处理无需登录的公开文章；搜索索引可能漏掉新文章，文章或转载无法证明具体官方岗位时只记作“待用户确认”。
- **核验：**岗位进入可投表前，必须是可识别的具体职位 URL，并且在可读取页面中找到职责或要求、地点/届别/实习信息和申请按钮。无法读取的动态页或跨站点链接进入线索，不伪装成可投岗位。
- **排序：**按方向、实习可行性、目标公司、AI/教育相关度、城市与薪酬的可解释规则计算暂定分。分数只是初筛，不能替代人工判断。
- **反馈：**在日报填写满意度、标记和备注；“待投递”进入进度区。“已投递”只有用户手动选择后才记录，实际投递日期、渠道、简历版本与附件引用由用户填写；有实际日期且满 21 天无更新时改为“无回复”。
- **自选岗位：**在日报的“手动加入”区域填写公司、具体岗位与链接即可直接进入待投递，不受自动核验或评分限制；若职位页无法读取，请同时粘贴 JD。
- **定制简历：**粘贴自己的简历母板后，在待投递岗位点击“准备简历”，把插件生成的提示词复制到已有的 WorkBuddy、豆包、元宝、Codex 等 AI 工具。将生成的草稿粘贴回插件、核对并确认，可下载 Markdown。插件不会代投。
- **备份：**在日报页点击“导出本机数据”。导出的 JSON 包含个人资料与简历母板，请自行保管，分享插件时不要分享备份文件。

## 目前的边界

- 浏览器须保持运行；电脑开着但浏览器完全退出时，扩展无法执行定时任务。重新打开浏览器后，会补做当天尚未完成的扫描和日报。
- 不访问需要登录、扫码或验证码的渠道，不自动投递，不自动调用朋友的 AI 账号。无 API Key 条件下，简历生成需要用户在已有 AI 工具中粘贴提示词与草稿。
- 公开网站的结构会变化。对纯前端动态渲染、图片型公众号和反爬页面，本原型可能只能记录线索，不能完成职位核验。请在日报“扫描记录”查看失败原因。
- 首版对岗位要求采用关键词初筛，无法理解复杂语义；复杂的毕业年份、投递名额和截止日期需以官网为准。
- 本原型已做静态检查，仍需在朋友实际使用的浏览器和目标网站逐站试用后才能作为稳定发布版。

## 文件

`manifest.json` 为扩展入口；`background.js` 负责定时扫描；`options.html` 为个人设置；`report.html` 为日报、反馈、进度和简历草稿；`popup.html` 为插件入口。
